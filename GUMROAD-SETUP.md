## Global Settings (Do These First)

Before creating products, configure these account-wide settings:

1. **Go to Settings > Profile**
   - Display name: `Teach4Texas`
   - Bio: `STAAR test prep resources built by Texas teachers, for Texas teachers. Themed boot camps, review activities, and data tracking tools for grades 3-8.`

2. **Go to Settings > Payments**
   - Confirm your payout method is connected (Stripe or PayPal)

3. **Default product settings to apply to each listing:**
   - **Refund policy:** 30-day no-questions-asked refund
   - **Delivery:** PDF (digital download, delivered instantly after purchase)
   - **Content type:** Digital Product
   - **Ratings:** Enable customer ratings on all products

## Connecting Gumroad to teach4texas.com

### Option A: Embed Products on Your Resources Page

Add Gumroad embed code directly to your teach4texas.com resources page so visitors can browse and buy without leaving your site.

1. On each Gumroad product page, click **Share** and copy the **Embed** code.
2. Paste the embed snippet into your resources page HTML where you want the product to appear.
3. Example embed (replace YOUR_PRODUCT_ID):
   ```html
   <script src="https://gumroad.com/js/gumroad.js"></script>
   <a class="gumroad-button" href="https://teach4texas.gumroad.com/l/YOUR_PRODUCT_ID">Buy on Gumroad</a>
   ```

### Option B: Overlay Checkout (Recommended)

Use Gumroad's overlay checkout so the purchase modal pops up on your site without redirecting.

1. Add this script once in your site's `<head>`:
   ```html
   <script src="https://gumroad.com/js/gumroad.js"></script>
   ```

2. For each product button, use this link format:
   ```html
   <a class="gumroad-button" href="https://teach4texas.gumroad.com/l/YOUR_PRODUCT_ID">Get STAAR Wars Boot Camp - $29</a>
   ```

3. The checkout overlay will handle payment, delivery, and receipts automatically.
