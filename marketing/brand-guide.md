# Teach4Texas Brand Guide

## Logo Concept
- **Primary Logo:** Texas lone star with an apple silhouette inside it, "Teach4Texas" text below
- **Icon/Avatar:** Just the star-apple mark (for profile pics, favicons)
- **Colors:** Navy (#1B365D) star outline, Burnt orange (#BF5700) apple, White text on dark backgrounds

## Color Palette
- **Primary Navy:** #1B365D
- **Accent Orange:** #BF5700
- **Light Gray:** #F8F9FA
- **White:** #FFFFFF
- **Success Green:** #548235 (for growth/TIA content)
- **Gold:** #BF8700 (for premium/TIA designation content)

## Fonts
- **Headlines:** Bold sans-serif (Inter, Montserrat, or similar)
- **Body:** Clean sans-serif (Inter, Open Sans)

## Profile Picture Usage
- TPT Store: Star-apple icon on navy background
- Pinterest: Star-apple icon on navy background  
- Facebook: Star-apple icon on navy background
- Instagram: Star-apple icon on navy background
- All social: Consistent star-apple mark

## Tagline Options
- "Texas Teacher Tools That Actually Work"
- "STAAR Prep → Student Growth → TIA Designation"
- "Built by Texas Educators, for Texas Educators"
