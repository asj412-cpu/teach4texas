# 📊 Student Growth Tracking Template — Setup Guide

## Welcome!

Thank you for purchasing the **Student Growth Tracking Template**! This Google Sheets-based tool helps you track student assessment data, monitor growth over time, and identify STAAR readiness levels — all in one place.

---

## 🚀 Quick Start (5 Minutes)

### Step 1: Make Your Own Copy
1. Open the Google Sheets link provided with your purchase
2. Go to **File → Make a Copy**
3. Rename it (e.g., "2025-2026 Growth Tracker — Mrs. Smith — 4th Math")
4. Save it to your Google Drive

### Step 2: Set Up Your Class Roster (Tab 1)
1. Click the **Class Roster** tab at the bottom
2. Enter each student's information:
   - **Column A:** Student Last Name
   - **Column B:** Student First Name
   - **Column C:** Student ID Number
   - **Column D:** Subgroup Tags — use the dropdown or type tags separated by commas:
     - `ELL` — English Language Learner
     - `SpEd` — Special Education
     - `GT` — Gifted & Talented
     - `504` — Section 504
     - `Dyslexia`
     - `At-Risk`
     - `Bilingual`
   - **Column E:** Additional Notes (optional)
3. The template supports up to 35 students. Need more? Copy rows and drag formulas down.

### Step 3: Enter Assessment Scores (Tab 2)
1. Click the **Assessment Scores** tab
2. Student names auto-populate from your roster
3. Enter scores as **percentages (0-100)** in the appropriate columns:
   - **Pre-Test** (beginning of year/unit)
   - **Mid-Year Assessment**
   - **Unit Assessments** (up to 8 units)
   - **Post-Test** (end of year/unit)
   - **STAAR Mock 1, 2, 3** scores
4. Leave cells blank if an assessment hasn't been given yet — formulas will adjust automatically

### Step 4: Review Growth Analysis (Tab 3)
- This tab **auto-calculates** — no data entry needed!
- Growth percentages calculate automatically from your assessment scores
- **Color coding:**
  - 🔴 **Red** = Less than 10% growth (needs intensive intervention)
  - 🟡 **Yellow** = 10–20% growth (on track, monitor closely)
  - 🟢 **Green** = More than 20% growth (strong progress!)
- Use this tab for RTI meetings, parent conferences, and PLC discussions

### Step 5: Track STAAR Readiness (Tab 4)
1. Student names auto-populate
2. After each benchmark or mock STAAR, mark each student's performance level:
   - **D** = Did Not Meet Grade Level
   - **A** = Approaches Grade Level
   - **M** = Meets Grade Level
   - **MA** = Masters Grade Level
3. Track up to 4 assessment windows (BOY, MOY, Mock 1, Mock 2)
4. The sheet highlights movement between levels so you can see who's trending up or down

### Step 6: View Your Dashboard (Tab 5)
- This tab **auto-generates** class summary statistics
- See at a glance:
  - Class average scores per assessment
  - Distribution of STAAR readiness levels (pie chart)
  - Growth trends over time (line chart)
  - Subgroup performance comparison (bar chart)
  - Students needing intervention (auto-flagged)

## 💡 Tips for Success

### Data Entry Best Practices
- Enter scores consistently as percentages (0-100)
- Update scores within 1 week of each assessment
- Use the Notes column for context (e.g., "absent for Part 2," "tested with accommodations")

### Using the Data
- **PLC Meetings:** Share your Dashboard tab on the projector
- **Parent Conferences:** Print individual student rows from Growth Analysis
- **RTI/MTSS:** Filter the Growth Analysis tab by subgroup to identify patterns
- **Admin Walkthroughs:** Keep the Dashboard tab open to show data-driven instruction
- **TIA Portfolio:** Screenshot your growth data as evidence of student progress!

### Filtering & Sorting
- Use Google Sheets' built-in filter feature (Data → Create a Filter)
- Filter by subgroup to see only ELL students, SpEd students, etc.
- Sort by growth percentage to quickly identify highest/lowest growth

### Making Copies for Multiple Classes
- File → Make a Copy for each class period or subject
- Keep all copies in one Google Drive folder for easy access

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Names aren't showing in other tabs | Make sure you entered names in Tab 1 (Class Roster) first |
| Growth percentages show errors | Check that both pre-test AND post-test scores are entered |
| Colors aren't showing | Go to Format → Conditional Formatting and re-apply if needed |
| Charts look wrong | Make sure there are no blank rows between student entries |
| Need more than 35 students | Copy the last row and drag down; formulas will extend |
