## ⏰ How to Run This Week

### 2 Weeks Before
- [ ] Read LESSON-PLANS.md
- [ ] Buy supplies (DECORATIONS.md)
- [ ] Print student materials (STUDENT-MATERIALS.md)
- [ ] Send parent letter

### Weekend Before
- [ ] Set up hallway decorations (jungle vines, base camp signs)
- [ ] Set up classroom as Base Camp
- [ ] Organize daily "survival kits" (supply packets)

### Each Morning
1. Play nature/adventure sounds as students enter
2. Deliver the **Trail Briefing** (see teacher scripts)
3. Distribute daily survival challenge packet
4. Run themed activities
5. Award **Survival Badges** at end of day
6. Update the **Journey Map** — mark the day's terrain as conquered

---

## 💡 Pro Tips

1. **Wear khaki or a safari hat.** The sillier you go, the more they love it.
2. **Nature sounds are free.** YouTube has hours of jungle/ocean/mountain ambiance. Play it softly during independent work.
3. **The journey map is KEY.** Students love seeing visual progress. Mark each terrain as completed.
4. **Tribal Council is the highlight.** Save it for the end of each day — it's the reward.
5. **Survival kits = pencil pouches.** Put 2 pencils, an eraser, and a small snack in a ziplock. Label "Survival Kit." Kids go wild.
