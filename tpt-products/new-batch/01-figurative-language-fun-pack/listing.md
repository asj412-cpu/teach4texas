# 🎨 Figurative Language Fun Pack — 50+ Activities for Grades 3-5

### Because figurative language doesn't have to be confusing! 🎉

**The ULTIMATE figurative language resource** — packed with hands-on activities, games, and practice that make similes, metaphors, idioms, personification, and hyperbole STICK. Students learn through play, movement, and creative writing instead of boring worksheets.

## 📦 What's Inside:

### 🎯 40 Task Cards (8 per type)
- **Simile Cards** — Identify, create, and explain similes
- **Metaphor Cards** — Literal vs. figurative meaning
- **Idiom Cards** — Match idiom to meaning + illustrate
- **Personification Cards** — Find it in text + write your own
- **Hyperbole Cards** — Exaggeration station! Rewrite realistic vs. hyperbolic

### 🔍 Figurative Language Scavenger Hunt
- 20 clue cards hidden around the classroom
- Students identify the TYPE of figurative language on each card
- Recording sheet with answer key
- Works for centers, early finishers, or whole class

### 🎲 "Say What You Mean" Board Game
- 2-4 players, printable game board
- Draw a card → identify the figurative language → explain the meaning → advance!
- Bonus squares: "Write Your Own" challenges
- Takes ~15-20 minutes per game

### 🧩 Matching Activities (3 sets)
- **Simile Match** — Match the two halves ("as brave as..." → "...a lion")
- **Idiom Decoder** — Match idiom to its real meaning
- **Figurative vs. Literal** — Sort sentences into correct category

### ✍️ Creative Writing Activities
- "Figurative Language Story Starter" — Write a short story using ALL 5 types
- "Poetry Workshop" — Write a poem loaded with figurative language
- "Comic Strip Creator" — Illustrate the literal meaning of idioms (kids LOVE this)
- "Figurative Language Diary" — Rewrite a boring paragraph with figurative language

### 📝 Practice Worksheets (5 pages)
- One per figurative language type
- Identify → Explain → Create format
- STAAR 2.0 style questions included (multiple choice + open-ended)

### 📊 Assessment
- 20-question assessment covering all 5 types
- Multiple choice + short answer (STAAR format)
- Answer key included
- Can be used as pre-test AND post-test

### 💻 Google Slides Digital Version
- All task cards as interactive slides
- Drag-and-drop matching activities
- Digital scavenger hunt
- Paperless option for 1:1 classrooms
